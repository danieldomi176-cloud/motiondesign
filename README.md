# Motion Design Studio

Produção audiovisual editável com Remotion, React, TypeScript, Three.js e FFmpeg.

## AGEXA — campanha de lançamento

[Instruções, decisões de produção e entregas AGEXA](docs/agexa/README.md).

[Pré-visualização MP4](exports/agexa/AGEXA_Preview_540p.mp4) · [Projeto editável ZIP](exports/agexa/AGEXA_Editable_Project.zip)

```bash
npm ci
npm run studio
npm run agexa:stills
npm run agexa:preview
npm run agexa:render
```

As composições `AGEXA-Official` e `AGEXA-TikTok-15s` estão na pasta AGEXA do Studio. A versão principal tem 40 s e a curta 15 s. O render final usa 1080 × 1920 a 30 FPS; a prévia usa 540 × 960 a 15 FPS.

O guião comercial foi fornecido pelo utilizador. A plataforma não pôde ser auditada devido a bloqueio de rede: as visualizações são **conceptuais e estão identificadas**, o recurso da marca é derivado da referência enviada e a narração pt-MZ fica preparada para gravação humana. Estas limitações estão descritas nos relatórios; não se apresentam telas fictícias como interface oficial.
