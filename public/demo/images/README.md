# Imagens do demonstrativo

As imagens são **ilustrações fotorealistas geradas por IA** para este projeto. Não são fotografias documentais de jogadores ou partidas reais. Foram pedidas sem marcas, clubes ou figuras públicas.

- `strike.png`: fundo com remate, topo escuro para tipografia.
- `spin.png`: bola em movimento, plano intermédio.
- `goalkeeper.png`: defesa em estádio noturno.
- `ball.png`: bola com transparência alfa para parallax/motion graphics.

`credits.json` conserva a proveniência, base de direitos e SHA-256 de cada recurso. Os originais de geração ficam em `/workspace/generated_images` no ambiente desta sessão; as cópias neste diretório são autónomas e devem acompanhar o projeto.

Para trocar recursos, use ficheiros próprios ou com licença compatível com a publicação pretendida e atualize os créditos. A geração destas imagens não depende de chaves de API no repositório. As condições de reutilização são as condições de output aplicáveis à conta OpenAI; não se atribui uma licença de stock ou Creative Commons inexistente.

## Raphinha × Mbappé

- `raphinha.png`: retrato em colagem editorial gerado por IA; camisa genérica azul e vermelha.
- `mbappe.png`: retrato em colagem editorial gerado por IA; camisa genérica branca.

Estes dois retratos representam figuras públicas numa interpretação ilustrada. Não são fotografias documentais, imagens oficiais nem sinais de aprovação. Não contêm escudos ou patrocinadores.
